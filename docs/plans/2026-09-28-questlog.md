# Party Quest Progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a `questlog` bot command answering in addon messages, and the `PlayerbotsPlusQuests` client addon showing the party's quest progress.

**Architecture:** Pure `QuestLogFormat` builds the reply lines; core `QuestLogAction` gathers the quest log (localized names) and sends `PPQ` addon whispers; the Lua addon polls party members with `BOT\t#a questlog` and renders a per-quest window.

**Tech Stack:** C++20 module (GoogleTest), Lua 5.1 / WoW 3.3.5 API.

**Spec:** `docs/specs/2026-09-28-questlog-design.md`

## Global Constraints

- Constraints of `docs/plans/2026-09-26-errands.md` apply; branch `questlog`; remote `github`.
- Addon prefix `PPQ`; request `BOT\t#a questlog`; reply lines ≤ 250 bytes, tab and `|` separators never inside fields.
- Status codes: 0 in progress, 1 complete, 2 failed.

### Task 1: QuestLogFormat (pure, TDD)

**Files:** create `src/Errands/QuestLogFormat.{h,cpp}`, `tests/QuestLogFormatTest.cpp`; modify `tests/CMakeLists.txt`.

**Produces:**

```cpp
struct QuestObjective { uint32_t done = 0; uint32_t required = 0; std::string name; };
struct QuestLine { uint32_t id = 0; uint8_t status = 0; std::string title; std::vector<QuestObjective> objectives; };
std::string FormatQuestLine(QuestLine const& line, size_t maxBytes = 250);
std::string CleanField(std::string const& text);  // tabs and '|' become spaces
```

- [ ] Tests: plain line `Q\t153\t1\tRed Leather Bandanas\t15/15:Red Leather Bandana`; two objectives joined by `|`; no objective → trailing empty field; separators in names cleaned; over 250 bytes: names shortened (≥ 8 chars kept) then last objectives dropped, never over the limit.
- [ ] Run: compile error. Implement. Run: pass. Commit.

### Task 2: questlog command (core)

**Files:** create `src/Errands/QuestLogAction.{h,cpp}`; modify `ErrandsStrategy.h` (trigger `questlog` → action `questlog`, `ChatCommandRelevance`), `PlayerbotsPlusRegistry.cpp` (trigger + action).

- [ ] For each quest slot: status from `GetQuestStatus` (COMPLETE → 1, FAILED → 2, else 0); title from `GetQuestLocale(id)->Title[locale]` when set, else `quest->GetTitle()`; objectives: `RequiredNpcOrGo[i]` with `RequiredNpcOrGoCount[i]` and `GetQuestSlotCounter(slot, i)` (creature name or gameobject name, localized), then `RequiredItemId[i]` with `RequiredItemCount[i]` and `GetItemCount(item, true)` capped at required.
- [ ] Locale: `master->GetSession()->GetSessionDbLocaleIndex()`.
- [ ] Send each `FormatQuestLine` then `END` to the master only (`event.getOwner()` must be the master), as `CHAT_MSG_WHISPER` / `LANG_ADDON` packets with text `PPQ\t…` (`ChatHandler::BuildChatPacket`).
- [ ] Build the image; commit.

### Task 3: Addon

**Files:** create `client/PlayerbotsPlusQuests/PlayerbotsPlusQuests.toc`, `PlayerbotsPlusQuests.lua`.

- [ ] TOC: Interface 30300, SavedVariables `PlayerbotsPlusQuestsDB`.
- [ ] Own log: `GetNumQuestLogEntries`, `GetQuestLogTitle`, quest id from `GetQuestLink`, objectives from `GetQuestLogLeaderBoard` (`"name: 14/15"`), complete flag.
- [ ] Party: on refresh send `SendAddonMessage("BOT", "#a questlog", "WHISPER", name)` to each party member; collect `CHAT_MSG_ADDON` with prefix `PPQ` from `sender` until `END`; 5 s timeout → `(no answer)`.
