# Errands Craft and Master Offers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `errands craft` crafts for the group then for skill-ups; share and craft offer upgrades to the master through an accepted trade.

**Architecture:** Pure: `SharePlanner` (master first), `CraftPlanner` (order, asks, answers). Core: `MasterGain`, `MasterOffer` state machine and `OfferToMasterAction`, `CraftItemAction`, `CraftAnswerAction`, `CraftDeclinedValue`.

**Tech Stack:** as v0.1.0.

**Spec:** `docs/specs/2026-09-27-craft-design.md`

## Global Constraints

- Constraints of `docs/plans/2026-09-26-errands.md` apply; branch `professions` (ships in v0.5.0); remote `github`.
- Relevances: offer 1.97, share 1.95, craft 1.93, hunt 1.9.
- Offer timings: request 30 s; declined entry 30 min. Craft question expires after 2 min; craft scan every 5 s.
- Chat commands `craft yes` / `craft no` are separate triggers; upstream `craft` stays untouched.

### Task 1: Share master-first (pure, TDD)

`ShareItem`: `float masterGain = 0.f; bool masterDeclined = false;`; `ShareSnapshot`: `uint64_t master = 0;`; `ShareDecision`: `bool toMaster = false;`.
`BestReceiver` returns the master first when `master && masterGain > 0 && !masterDeclined && !WantsToEquip(item.usage) && item.usage != Quest`. `WantedByGroup` returns true for such items.

Tests: `ShareMaster.MasterFirst`, `ShareMaster.DeclinedFallsBackToBots`, `ShareMaster.HolderKeepsItsUpgrade`, `WantedByGroup.MasterCounts`.

### Task 2: CraftPlanner (pure, TDD)

```cpp
struct RecipeOption { uint32_t spell, product; bool castable, usefulToGroup, usefulToMaster, declined, skillUp; uint32_t reagentCost; };
struct CraftSnapshot { bool errandsIdle; std::vector<RecipeOption> recipes; };
struct CraftConfig { uint32_t askTimeoutMs = 120000; };
struct CraftState { uint32_t askedSpell, askedProduct, askedAt, approvedSpell, approvedProduct; std::string lastReason; };
enum class CraftAction : uint8_t { None, Craft, Ask };
struct CraftDecision { CraftAction action; uint32_t spell, product; bool forMaster; std::string reason; };
CraftDecision PlanCraft(CraftSnapshot const&, CraftState&, CraftConfig const&, uint32_t now);
bool AnswerCraft(CraftState&, bool yes);  // false when nothing was asked
```

Tests: gate; waiting for an answer; expiry; approved crafted first and cleared; approved but not castable dropped; ask before group; declined never asked; group before skill-up; cheapest first; nothing castable → none; `AnswerCraft` yes/no/nothing.

### Task 3: Core side, build

- `MasterGain(Player* master, ItemTemplate const*, int32 randomProperty)` in `GroupItems`.
- `ErrandsData`: `MasterOffer offer` (`item`, `entry`, `startedAt`, `requested`, `placed`), `offerDeclined` (entry → time), `CraftState craft`, `CraftDecision craftDecision`, `lastCraftScanAt`, `pendingOfferProduct`, `pendingOfferSince`.
- `OfferToMasterAction` (`"offer to master"`, in `ErrandsStrategy`, relevance 1.97): progresses the offer (request `CMSG_INITIATE_TRADE`, place with `CMSG_SET_TRADE_ITEM`, detect success/decline); turns `pendingOfferProduct` into an offer once crafted (15 s max).
- `ShareItemAction`: fills `master`/`masterGain`/`masterDeclined`; a `toMaster` decision starts an offer instead of a transfer.
- `RunErrandAction::ExtraJunk`: uses the master-aware `WantedByGroup`.
- `CraftItemAction` (`"craft item"`), `CraftAnswerAction` (`"craft yes"`, `"craft no"`), `CraftDeclinedValue` (`"craft declined"`, saved), `ErrandsCraftStrategy` (`"errands craft"`).
- Registry and status line. Full build.
