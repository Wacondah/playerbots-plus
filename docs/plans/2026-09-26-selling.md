# Errands Selling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At a vendor, errands also sells bound junk (`ITEM_USAGE_VENDOR`) and tradeable items (`ITEM_USAGE_AH`) no bot of the group wants, up to `MaxSellQuality` (default 3, blue).

**Architecture:** A pure `WantedByGroup(ShareItem const&)` in `SharePlanner`, sharing the `PlanShare` rules. The per-item group description moves from `ShareItemAction` to `GroupItems.{h,cpp}` so sharing (10 yd) and selling (any distance) use the same code. `RunErrandAction` computes the extra junk list and sells it item by item with mod-playerbots' `SellAction::Sell(Item*)`.

**Tech Stack:** as v0.1.0.

**Spec:** `docs/specs/2026-09-26-selling-design.md`

## Global Constraints

- Constraints of `docs/plans/2026-09-26-errands.md` apply; branch `hunt`; remote `github`.
- Never sell equipped items, items without a sell price, or usages other than `VENDOR`/`AH` (plus the unchanged grey/white rules).
- `PlayerbotsPlus.Errands.MaxSellQuality`: default 3, clamped to 0..4.
- Never use upstream `sell vendor` (ignores quality and group).

#ifndef PLAYERBOTS_PLUS_GROUP_ITEMS_H
#define PLAYERBOTS_PLUS_GROUP_ITEMS_H

#include "Bag.h"

#include "SharePlanner.h"

class PlayerbotAI;

namespace PlayerbotsPlus
{
// Every item in the bot's bags (never equipped ones).
template <class Fn>
void ForEachBagItem(Player* bot, Fn fn)
{
    for (uint8 slot = INVENTORY_SLOT_ITEM_START; slot < INVENTORY_SLOT_ITEM_END; ++slot)
        if (Item* item = bot->GetItemByPos(INVENTORY_SLOT_BAG_0, slot))
            fn(item);
    for (uint8 bagSlot = INVENTORY_SLOT_BAG_START; bagSlot < INVENTORY_SLOT_BAG_END; ++bagSlot)
        if (Bag* bag = bot->GetBagByPos(bagSlot))
            for (uint32 i = 0; i < bag->GetBagSize(); ++i)
                if (Item* item = bag->GetItemByPos(i))
                    fn(item);
}

// Other living bots of the bot's group; maxDistance 0 means any distance.
std::vector<Player*> GroupBots(Player* bot, float maxDistance);

// What the item means to its holder and to each of `others` (usage, tier, gain, held).
ShareItem DescribeForGroup(PlayerbotAI* holderAI, Item* item, std::vector<Player*> const& others);
}  // namespace PlayerbotsPlus

#endif

- [ ] **Step 2: `GroupItems.cpp`** — move `ToShareUsage`, `UsageFor`, `GainFor` from `ShareItemAction.cpp` into its anonymous namespace, then:

```cpp
std::vector<Player*> GroupBots(Player* bot, float maxDistance)
{
    std::vector<Player*> bots;
    Group* group = bot->GetGroup();
    if (!group)
        return bots;
    for (GroupReference* ref = group->GetFirstMember(); ref; ref = ref->next())
    {
        Player* member = ref->GetSource();
        if (!member || member == bot || !member->IsAlive() || !GET_PLAYERBOT_AI(member) ||
            member->GetMapId() != bot->GetMapId())
            continue;
        if (maxDistance > 0.f && bot->GetDistance(member) > maxDistance)
            continue;
        bots.push_back(member);
    }
    return bots;
}

ShareItem DescribeForGroup(PlayerbotAI* holderAI, Item* item, std::vector<Player*> const& others)
{
    uint32 const itemId = item->GetEntry();
    uint32 const usedBy = ReagentIndex::UsedBy(itemId);

    ShareItem s;
    s.id = item->GetGUID().GetRawValue();
    s.usage = ToShareUsage(UsageFor(holderAI->GetBot(), itemId));
    s.tier = TierFor(usedBy, ReagentIndex::Known(holderAI->GetBot()));
    for (Player* other : others)
    {
        ShareReceiver r;
        r.guid = other->GetGUID().GetRawValue();
        r.usage = ToShareUsage(UsageFor(other, itemId));
        r.tier = TierFor(usedBy, ReagentIndex::Known(other));
        r.gain = (r.usage == ShareUsage::Equip || r.usage == ShareUsage::Replace) ? GainFor(other, item) : 0.f;
        r.held = other->GetItemCount(itemId, true);
        s.receivers.push_back(r);
    }
    return s;
}
```

```cpp
bool RunErrandAction::HasJunk()
{
    bool basic = false;
    ForEachBagItem(bot, [&](Item* item) { basic = basic || IsBasicJunk(item); });
    return basic || !ExtraJunk().empty();
}

// Beyond greys/whites: bound junk, and tradeables no bot of the group would take.
std::vector<Item*> RunErrandAction::ExtraJunk()
{
    std::vector<Item*> junk;
    uint32 const maxQuality = Config().maxSellQuality;
    std::vector<Player*> group;
    bool groupLoaded = false;

    ForEachBagItem(bot,
                   [&](Item* item)
                   {
                       ItemTemplate const* proto = item->GetTemplate();
                       if (!proto->SellPrice || proto->Quality == ITEM_QUALITY_POOR || proto->Quality > maxQuality)
                           return;
                       ItemUsage const usage = AI_VALUE2(ItemUsage, "item usage", int32(proto->ItemId));
                       if (usage == ITEM_USAGE_VENDOR)
                       {
                           junk.push_back(item);
                           return;
                       }
                       if (usage != ITEM_USAGE_AH || !item->CanBeTraded())
                           return;
                       if (!groupLoaded)
                       {
                           group = GroupBots(bot, 0.f);
                           groupLoaded = true;
                       }
                       if (!WantedByGroup(DescribeForGroup(botAI, item, group)))
                           junk.push_back(item);
                   });
    return junk;
}
```
